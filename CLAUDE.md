# content-gen — правила для Claude Code

Инструмент генерирует фото/видео одного ИИ-персонажа файлами, без публикации.
Полное ТЗ — в истории задачи; здесь только рабочие правила репозитория.

## Экономия — обязательна, не опциональна

- `init-persona`: ровно 1 LLM-вызов и ровно 2 генерации изображений в дефолтном режиме.
- `generate`: 1 генерация + максимум 1 ретрай по умолчанию.
- Любое расширение расхода (`--variants`, `--full-reference-set`, `--retries`) — только через явный флаг.
- Vision-LLM для QC не подключать. Сходство лица — только через embedding-модель.
- Для M2/M3 обязателен тест, считающий реальное число вызовов LLM/image-провайдера за прогон.

## Прочие правила

- Не выдумывать сигнатуры внешних API. Нет документации — адаптер с `NotImplementedError` + мок + TODO со ссылкой.
- Промпты — файлами в `prompts/`, не строками в коде.
- Секреты — только из env (`.env`, см. `.env.example`).
- Никакой сети в тестах — внешние API только через моки.
- Двигаться этап за этапом (см. раздел 9 ТЗ), ничего из следующих этапов "заодно".
